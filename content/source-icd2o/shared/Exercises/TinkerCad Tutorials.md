## TinkerCad has some fantastic built in tutorials that will help you learn the basics of the program

1. Navigate to the left hand side of the website and find "Tutorials"
2. You should see the basic tutorials in order. Click on the first one (Place it) and complete it
![[Pasted image 20241214204252.png]]
3. Continue working on the tutorials until you have completed the first 13 tutorials (Place it, View it, Move it, Rotate it, Size it, Group it, Copy it, Duplicate it, Hide it, Align it, Creating Holes, Camera controls and finally "Let's Learn TinkerCad"
>[!tip] Remember, I can see your tutorial completion!
